Bagikan web ini

Tempel link web kamu di kotak ini, lalu salin dan kirim ke teman atau publik. Pengunjung hanya bisa melihat: mereka tidak mendapat menu edit.

Supaya aman (dilakukan di claude.ai):

  1. Buka link web ini di tab browser baru, lalu klik Share di bagian atas halaman (di luar website ini).
  2. Atur akses sebagai viewer (hanya melihat). Jangan tambahkan siapa pun sebagai editor.
  3. Tekan Terbitkan lebih dulu supaya perubahan terakhir ikut terlihat.
Tombol Share dan pengaturan akses milik claude.ai, bukan bagian website ini, jadi tidak bisa ditaruh di dalam halaman. Kalau tidak muncul, kemungkinan akunmu belum mengizinkan berbagi untuk halaman ini.
